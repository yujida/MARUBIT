진행 원칙

한 사이클 = 설명 한 장(강사 화면으로 한 번) → 따라하기 한 장(번호 순서대로 다 같이) → 확인(화면이 이렇게 됐으면 성공). 크루 전원 완료 카드가 서면 다음 사이클. 먼저 끝난 사람은 옆 사람 돕기, 막히면 옆 사람 → 크루 → 강사 호출 카드. 크루장은 전원 완료 확인만 하면 됩니다.

상황대응
재료(내 컷)가 없다드라이브 "3회차 실습 소스"나 CapCut 무료 스톡 영상으로 똑같이 진행. 과제에서 내 컷으로 다시
크루마다 속도 차이가 크다먼저 끝난 크루는 해당 사이클의 "도전"(속도 곡선 · 비트 맞추기 · 마스크 키프레임)으로, 늦은 크루 옆에 강사가 먼저
"미디어 없음" 표시원본 파일을 옮김 → 다시 연결하거나 원본 폴더로 되돌리기
영상이 안 열리거나 끊김HEVC · HDR 영상. 1회차 폰 설정(호환성 · HDR 끄기)을 다시 안내
Pro 표시가 뜬다유료 계정으로 로그인됐는지 확인. 안 되면 같은 결과의 무료 기능으로 대체
키프레임 ◇가 안 보인다클립부터 선택. 그룹 클립 · 일부 템플릿은 안 될 수 있음

3회차 요약 영상 대본 (약 75초, 세로 9:16)

수업 다음 날 단톡방에 올릴 영상입니다. 강사 화면 녹화와 수업 장면으로 CapCut에서 만들고, 자막은 아래 문장을 그대로 씁니다. 오늘 배운 기능을 영상 안에서 직접 보여 주면 복습이 됩니다.

시간화면자막 · 내레이션
0–3초크루가 함께 화면을 보며 웃는 장면 (정지 프레임으로 끝)"오늘 우리는 편집을 처음부터 끝까지 했습니다"
3–15초타임라인에서 Q · W로 자르는 화면 녹화 (2배속)고르고, 자르고, 붙이고, 다듬기. 재생헤드 놓고 Q · W
15–30초가로 컷이 세로로 채워지는 장면 · 색 맞추기 전후 분할 화면세로에 맞추고, 한 영상처럼 색을 맞추기

45–60초글자 뒤로 사람이 지나가는 장면 · 원 마스크 리빌레이어를 쌓고, 마스크로 보이는 곳을 정하고, 키프레임 두 점으로 움직이기
