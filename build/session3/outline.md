# 3회차 개요 · 11/19(목) · CapCut 완전정복

모든 3회차 자료(슬라이드 · 워크북 · 핸드북 3장 · 진행안)의 기준. 수강생 실명 · 개인 사정은 쓰지 않는다(공개 저장소). 교시별 시각은 적지 않는다. 크루 역할은 크루장 한 명뿐, 나머지는 서로 돕는다.

## 이번 회차의 원칙

- 1회차 촬영 → 2회차 기획 → **3회차 편집**. 4 · 5회차에 장르별 실습을 하려면 오늘 CapCut 기능을 손에 익혀야 한다.
- 지난 방식("와르르 설명하고 해 보세요")을 버리고 **설명 → 따라하기 → 확인**을 작은 단위로 반복한다. 한 사이클 = 개념 1장 + 따라하기 1장(번호 매긴 클릭 순서) + 확인(화면이 이렇게 됐으면 성공).
- 확인 규칙: "모두의 화면이 같아질 때까지" 다음으로 넘어가지 않는다. 크루 전원 완료 카드가 서면 다음 사이클. 먼저 끝난 사람은 옆 사람을 돕는다. 막히면 옆 사람 → 크루 → 강사 호출 카드.
- 실습 재료: **공통 샘플 "한강 단풍, 지금이에요"**(강사가 CapCut AI로 만든 세로 브이로그, 가상 인물 · 가상 시나리오, 드라이브 "3회차 공통 샘플"). 사이클 1~21은 모두 같은 샘플로 따라 해서, 화면을 서로 비교하며 "모두의 화면이 같아질 때까지"를 지킨다.
- 공통 샘플 구성(파일 이름 = 슬라이드 · 워크북에서 부르는 이름): 01_훅_슬로 · 02_동작_와이드 · 03_동작_클로즈업(02와 같은 동작) · 04_가로컷(16:9) · 05_지나가는사람 · 06_한마디(대사 없음) · 07_비포 · 08_애프터(07과 같은 구도) · 09_다른장소 + 여분 씬 11_발걸음_낙엽 · 12_자전거_시점 · 13_나뭇가지_하늘 + 내레이션.mp3(Fish Audio) · 음악_배경 · 로고.png. 여분 씬은 대본에 자리가 없어 넣을지 · 어디에 둘지가 편집자의 의도(편집 방향: 감성 브이로그 / 활기 숏폼 / 정보형 소개). 대본 · 스토리보드 · 준비 목록은 lectures/03/공통샘플_대본_한강단풍.md · 공통샘플_스토리보드_한강단풍.md · 공통_샘플_준비_목록.md.
- **나만의 한 편**(사이클 21 다음, 7교시): 배운 기능으로 각자 한 편 더 편집. A 찍어 온 내 영상이 있으면 내 영상 / B 없으면 "3회차 추가 샘플" = 강사가 오늘 찍은 스케치(학교 모습 · 점심시간 구내식당 · 수업 장면, 넉넉하게). 이번엔 대부분 B. 얼굴이 나오면 "일부 공개". 꼭 넣을 것: 기본 여섯(가편집 2–4 · 세로 5 · 색 7 · 음악 8 · 자막 9–10 · 제목 11) + 레이어 12–14 · 전환/이펙트 15–16 · 마스크 17–18 · 키프레임 19–21 중 하나 이상. 사이클 22 · 23(내보내기 · 업로드)은 이 한 편으로 한다.
- 오늘 남는 것: 공통 샘플 연습본 1편 + 나만의 한 편 1편(채널 업로드 = 트리의 첫 오너먼트).
- 수강생 PC는 소리가 나지 않는다. 소리는 파형 · dB 숫자로 맞추고(목소리 0dB · 음악 −15 ~ −20dB · 페이드 아웃 2초), 듣는 확인은 폰으로(CapCut 클라우드 → 폰 앱, 내보내기 → 드라이브 → 폰, 업로드 후 폰 유튜브 앱).
- CapCut PC 메뉴 이름은 버전마다 조금씩 다르다. 자료에는 메뉴 위치를 설명형으로 쓰고 영어 이름을 괄호로 함께 적는다. 강사는 수업 전 설치된 버전에서 한 번 확인.

## 확인된 메뉴 · 단축키 (공개 자료 기준)

- 분할 Ctrl+B · 재생헤드 왼쪽 삭제 Q · 오른쪽 삭제 W · 재생/정지 Space · 되돌리기 Ctrl+Z · 타임라인 확대/축소 Ctrl + 마우스 휠(또는 + / -). 단축키는 키보드 아이콘에서 확인 · 변경 가능.
- 배경 제거: 클립 선택 → 오른쪽 패널 '비디오' → '컷아웃'(Cutout) → '자동 컷아웃' 체크. 크로마 키: 같은 '컷아웃' 탭에서 크로마 키 → 스포이드로 초록 찍기 → '강도' · '그림자' 조절.
- 키프레임: 클립 선택 → 오른쪽 패널 '비디오'의 위치 · 크기 · 회전 · 불투명도 옆 ◇(다이아몬드) 버튼. 클립을 먼저 선택해야 보인다.
- 내보내기: 오른쪽 위 '내보내기' → 이름 · 해상도 · 형식 · 프레임 속도 · 코덱 설정.
- 확인 필요(버전마다 이름이 다를 수 있음): 마스크(Mask) 탭 위치와 모양 이름, 혼합 모드(Blend), 자동 캡션(Auto captions) 위치와 옵션(키워드 강조 · 군말 찾기 · 이중 자막), 캡션 템플릿, 텍스트 읽기(TTS), 전환 '모두 적용', 비트 표시(음악 클립 우클릭), 효과 탭(비디오 효과 · 바디 효과), 음량 정규화, 캔버스 · 배경 흐림(Canvas/Background), 속도 곡선(Curve), 소음 제거(Reduce noise), AI 동영상(미디어 → AI 미디어).

## 오프닝

- 표지 → 오늘의 흐름(사이클 23개, 남는 것 = 연습본 1 + 나만의 한 편 1) → 오늘의 방식(설명 → 따라하기 → 확인) → 오늘의 공통 샘플(한강 단풍 · 편집 방향 셋).
- 크루 체크인은 하지 않는다(찍어 온 사람이 거의 없음). 스케치 촬영 동의 안내만.

## 1교시 · 편집의 기초와 CapCut 첫 만남

- 편집이란 = 고르기 · 자르기 · 붙이기 · 다듬기. 편집 순서: 정리 → 가편집(순서대로 붙이기) → 본편집(리듬 · 소리 · 자막 · 색) → 마스터링 → 내보내기. 1회차 제작 공정 7단계의 4 · 5단계.
- 편집자가 하는 질문 세 가지: 3초 안에 무슨 영상인지 아나 / 지루한 곳이 없나 / 소리 없이 봐도 이해되나.
- CapCut PC 화면 다섯 구역: ① 위쪽 도구 탭(미디어 · 오디오 · 텍스트 · 스티커 · 효과 · 전환 · 필터 · 조정 등) + 왼쪽 자료 창 ② 가운데 재생 화면(플레이어) ③ 오른쪽 속성 패널(선택한 클립의 설정) ④ 아래 타임라인 ⑤ 오른쪽 위 내보내기.
- 사이클 1 · 새 프로젝트: 프로젝트 만들기 → "3회차 공통 샘플" 폴더를 미디어 창에 끌어다 놓기 → 화면 비율 9:16 → 프로젝트 이름 "3회차_연습_내이름". 확인: 세로 캔버스 + 미디어 창에 영상 12개 · 내레이션 · 음악 · 로고.
- 파일 정리 원칙: 원본 폴더 하나에 모으고 옮기지 않기(옮기면 "미디어 없음"). 프로젝트는 자동 저장.

## 2교시 · 컷 편집: 타임라인 기본기

- 타임라인 읽기: 재생헤드(세로선), 트랙(줄), 메인 트랙(맨 아래 영상 줄), 클립(블록). 위 트랙일수록 화면 앞.
- 사이클 2 · 올리고 움직이기: 컷 5개를 메인 트랙에 순서대로 → 끌어서 순서 바꾸기 → Space로 재생 → 타임라인 확대 · 축소. 확인: 5컷이 빈틈없이 한 줄.
- 자르는 네 가지 방법: 분할(Ctrl+B) · 왼쪽 삭제(Q) · 오른쪽 삭제(W) · 클립 끝 끌기(트림). 메인 트랙은 자르면 뒤가 자동으로 붙는다(자석).
- 사이클 3 · 15초 가편집: 컷마다 가장 좋은 2~4초만 남기기, 훅 컷을 맨 앞으로. 확인: 전체 15초 안팎, 첫 3초에 훅.
- 컷 리듬: 1회차 컷의 문법 연결 — 같은 동작은 다른 크기로 이어 붙이기(동작 연결), 같은 크기 연속은 점프컷, B롤로 덮기. 쇼츠는 한 컷 평균 1.5~3초.
- 사이클 4 · 동작 연결 컷: 같은 동작을 찍은 두 컷을 동작 중간에서 잘라 이어 붙이기. 확인: 끊김 없이 하나의 동작처럼.

## 3교시 · 화면 다듬기: 크기 · 속도 · 색

- 크기 · 위치 · 회전 · 자르기: 오른쪽 패널 '비디오' 기본(변환) 값 또는 플레이어에서 직접 끌기. 가로로 찍은 컷을 9:16에 넣으면 위아래가 빈다 → 크기 키우기 또는 배경 흐림 채우기(캔버스 · Background).
- 사이클 5 · 세로 맞추기: 가로 컷 하나를 세로 화면에 꽉 차게 or 배경 흐림. 확인: 검은 띠 없음.
- 속도: 일반 속도(0.5x 슬로 · 2x 빠르게), 곡선 속도(Curve), 정지 프레임(Freeze), 역재생(Reverse). 60fps로 찍은 컷은 0.5x가 부드럽다(1회차 프레임레이트).
- 사이클 6 · 훅 슬로 + 정지: 훅 컷을 0.5x로, 마지막 컷 끝에 정지 프레임 1초. 확인: 첫 3초가 부드럽게 느려짐.
- 색 맞추기: '조정'(Adjust)에서 밝기 · 대비 · 채도 · 색온도. 1회차 화이트밸런스 연결 — 컷마다 색이 다르면 한 영상처럼 안 보인다. 필터는 약하게(강도 낮춤). 같은 설정을 다른 클립에 복사 · 붙여넣기 또는 조정 레이어로 전체 적용.
- 사이클 7 · 한 영상처럼: 기준 컷 하나를 정해 나머지 컷의 밝기 · 색온도를 맞추기. 확인: 5컷이 같은 날 같은 빛처럼.

## 4교시 · 소리와 자막

- 소리 네 층: 말(목소리) · 현장음 · 음악 · 효과음. 말이 들리게 음악은 낮게. 영상 원본 소리 끄기(음소거) · 볼륨 · 페이드 인/아웃 · 소음 제거.
- 음악 저작권: CapCut 음악 라이브러리 곡이라도 유튜브 · 상업적 사용 가능 여부를 확인. 안전한 선택은 유튜브 오디오 보관함 · 직접 녹음. 사업 홍보 채널은 특히 주의.
- 사이클 8 · 음악 깔기: 음악 넣기 → 볼륨 낮추기 → 끝 2초 페이드 아웃 → 컷 바뀌는 곳을 박자에 맞추기(비트 표시가 있으면 사용). 확인: 음악이 영상 끝에서 자연스럽게 끝남.
- 자막: 자동 캡션(Auto captions)으로 말을 자막으로 → 오탈자 고치기 → 스타일 하나로 통일 → 위치는 세로 안전 영역(위 · 아래 · 오른쪽 피하기, 1회차). 말이 없는 영상은 텍스트로 한 줄 자막.
- 사이클 9 · 자막 달기: 내레이션.mp3로 자동 캡션 생성 → 고치기 → 스타일 통일 → 위치. 확인: 소리 끄고 봐도 이해됨.
- CapCut 자동 자막 기능 다섯: 자동 캡션 · 스타일/캡션 템플릿 · 키워드 강조/군말 찾기(대본으로 편집) · 텍스트 읽기(TTS) · 자동 가사/이중 자막. 일부는 Pro · 횟수 제한.
- 사이클 10 · 자막 꾸미기: 캡션 템플릿 전체 적용 → 강조 단어 하나 → 말 없는 컷에 TTS. 확인: 강조 단어가 먼저 보이고 말 없는 컷에도 목소리.
- AI 목소리 세 가지 비교(CapCut TTS / Fish Audio / ElevenLabs): 무료 분량 · 가입 · 작업 순서 · 자막 연결 · 목소리 · 무료 이용 조건 · 속도. 수업은 CapCut TTS가 기본, **Fish Audio 하나만 강사 시연**(ElevenLabs는 비교만). 규칙: 기본 목소리만 · 복제는 본인만 · 사람처럼 들리면 AI 표시 · 무료 플랜 목소리는 수익화 영상에 쓰지 않기.
- 사이클 11 · 제목 텍스트: 첫 3초에 제목 한 줄 + 텍스트 등장 애니메이션(In). 확인: 3초 안에 무슨 영상인지 앎.

## 5교시 · 레이어 · 전환 · 이펙트

- 레이어 = 투명 필름 겹치기. 위 트랙일수록 화면 앞. 메인 트랙(바닥) 위에 영상 · 사진 · 텍스트 · 스티커를 쌓는다. 순서는 트랙을 위아래로 옮겨 바꾼다.
- 사이클 12 · 화면 속 화면(PiP): 클립 하나를 메인 트랙 위로 올리기 → 크기 줄이기 → 모서리로. 확인: 큰 화면 위에 작은 화면.
- 불투명도 · 혼합 모드(Blend): 위 레이어를 반투명하게, 또는 '화면 · 곱하기' 같은 혼합으로 빛 · 질감 겹치기. 로고 · 워터마크는 PNG(투명 배경) 이미지로.
- 사이클 13 · 세 겹 쌓기: 배경 영상 + 로고 PNG(또는 스티커) + 텍스트. 확인: 레이어 순서를 바꾸면 무엇이 가려지는지 직접 봄.
- 배경 제거: '비디오' → '컷아웃' → 자동 컷아웃(인물 누끼). 초록 배경이면 크로마 키(스포이드 · 강도 · 그림자).
- 사이클 14 · 썸네일형 인트로: 06_한마디 누끼 → 아래 트랙에 다른 배경 → 위에 큰 제목. 확인: 인물만 떠 있는 첫 화면.
- 전환은 뜻으로 고른다: 디졸브 · 페이드(시간 흐름) / 슬라이드 · 와이프(순서 · 목록) / 줌 · 카메라 흔들림(에너지) / 블러 · 휩(장소 바뀜) / 글리치 · 모양(테크 · 모양으로 열기).
- 전환을 잘 쓰는 다섯 가지: 한 영상에 한두 종류 · 0.3~0.5초 · 바뀌는 곳에만 · 박자 위에 · 움직임 잇기. 찍을 때 만드는 전환: 휩 팬 · 가리기 · 매치 컷.
- 사이클 15 · 전환 넣기: 장소가 바뀌는 이음새 하나에 디졸브 0.4초, 다른 종류와 비교 후 하나만. '모두 적용'은 해 보고 되돌리기. 확인: 한 곳에만 0.4초.
- 이펙트 · 애니메이션 · 비트: 비디오 효과(흔들림 · 플래시 · 빛샘 · 필름) · 바디 효과 · 클립 애니메이션 · 비트 표시(음악 우클릭).
- 사이클 16 · 비트에 맞춘 이펙트: 비트 표시 → 이음새를 비트 점에 → 흔들림 · 플래시 0.3~0.5초. 확인: 박자에 맞춰 화면이 "탁".

## 6교시 · 마스크와 키프레임

- 마스크(Mask) = 화면의 어느 부분만 보이게 하는 "구멍". 모양: 선형(일자) · 미러(띠) · 원 · 사각형 · 하트 · 별(이름은 버전마다 다를 수 있음). 위치 · 크기 · 회전 · 가장자리 흐림(페더) · 반전.
- 사이클 17 · 분할 화면: 두 컷을 위아래 트랙에 겹치고 위 클립에 선형 마스크 → 반반 화면(비포 · 애프터). 확인: 경계선이 부드럽게.
- 사이클 18 · 글자 뒤로 지나가는 사람: 배경 영상(메인) + 텍스트(위) + 같은 영상을 복제해 맨 위에 올리고 자동 컷아웃 → 사람이 글자 앞으로 지나감. 확인: 사람에 가려지는 글자.
- 키프레임 = 시작 상태와 끝 상태를 두 점으로 찍으면 그 사이를 CapCut이 자동으로 채운다. 순서가 핵심: ① 재생헤드를 시작 위치로 ② ◇ 눌러 첫 점 ③ 재생헤드를 끝 위치로 ④ 값 바꾸기(두 번째 점이 자동으로 생김).
- 사이클 19 · 줌인: 크기 100% → 120%를 3초 동안 = 1회차 "줌 말고 달리"를 편집으로 흉내(Ken Burns). 확인: 천천히 다가가는 화면.
- 사이클 20 · 날아와서 멈추는 글자: 텍스트 위치 키프레임(화면 밖 → 가운데) + 불투명도 0 → 100. 확인: 글자가 미끄러져 들어와 멈춤.
- 사이클 21 · 마스크 리빌: 원 마스크 크기를 0 → 화면 가득 키프레임 → 다음 장면이 동그랗게 열림(1회차 리빌의 편집 버전). 확인: 구멍이 커지며 장면 전환.
- 키프레임 팁: 클립을 먼저 선택해야 ◇가 보인다. 두 점 사이가 짧을수록 빠르다. 처음엔 두 점만.

## 7교시 · 나만의 한 편 · 첫 오너먼트

- 나만의 한 편 · 두 갈래(손 들어 A · B 확인) → 꼭 넣을 것(기본 여섯 + 하나 이상).

- 마스터링 체크 7: 소리 켜고 한 번(폰으로) · 끄고 한 번 / 음량(말이 음악보다 크게) / 자막 오탈자 / 컷마다 색 / 첫 3초 / 마지막 1초(정지 · 로고) / 세로 안전 영역.
- 사이클 22 · 내보내기: 오른쪽 위 '내보내기' → 이름(날짜_채널_제목) · 해상도 1080p · 프레임 속도 30fps(촬영과 같게) · 형식 MP4 · 코덱 H.264(호환성) → 저장 위치 확인. 확인: 폰으로 옮겨 재생해 봄.
- 사이클 23 · 쇼츠 업로드: 2회차에 연 채널에 업로드(발행 전 다섯 가지: 제목 · 첫 화면 · 설명 · 공개 범위 · AI 표시). 일부 공개도 OK. 업로드 후 폰 유튜브 앱으로 소리 확인.
- 크루 상영회: 크루 안에서 나만의 한 편을 폰으로 돌려 보기("왜 이 컷을 첫 장면으로?") → 칭찬 1 + 제안 1(모두가). 크루 트리 현황판에 첫 오너먼트 스티커.
- 4 · 5회차 예고: 장르별 실습(숏폼 · 브이로그 · 정보성 · 스트리머형 · AI 영상, 그리고 브랜딩 · 후킹). 오늘 익힌 기능을 장르마다 다시 쓴다.
- 과제: 나만의 한 편 다듬어 채널 업로드(B로 한 사람은 다음 회차 장르로 내 영상 찍어 오기) + 다음 회차 장르 하나 고르고 촬영 소스 모으기.
