오늘의 목표 세 가지

  1. 기술(촬영 · 기획 · 편집)을 카테고리로 묶어, 브이로그 · 정보성/리뷰 · 상품 이미지 · 챌린지를 A 정의부터 G 체크까지 한 번씩 돌린다
  2. 플랫폼 두 갈래(유튜브 롱폼 / 릴스 · 쇼츠 · 틱톡)의 문법 차이를 알고 같은 촬영으로 둘 다 만든다
  3. 수업 날 브이로그 롱폼 1편 + 숏폼 1편(상품 이미지 또는 크루 챌린지)을 올린다 (오너먼트 두 개)

진행 원칙

카테고리마다 같은 순서: A 정의 → B 레퍼런스 → C 기획 → D 촬영 → E 편집(따라하기) → F 발행 → G 체크. 따라하기는 3회차처럼 "모두의 화면이 같아질 때까지", 크루 전원 완료 카드가 서면 다음. 수업 시작부터 브이로그 촬영이 계속되니 쉬는 시간 · 점심에 찍도록 계속 상기. PC는 소리가 안 나므로 소리는 파형 · dB · 폰으로.

4회차 요약 영상 대본 (롱폼 약 2분 + 숏폼 20초)

오늘 배운 것을 그대로 보여 주는 요약 영상입니다. 강사의 수업 날 브이로그를 그대로 쓰고, 하이라이트를 세로로 하나 더 내보내면 "한 번 찍고 여러 번 쓰기" 시범이 됩니다.

구간화면자막 · 내레이션
인트로아침 교실 셀프캠 + 하이라이트 1초(크루 챌린지 웃음)"오늘은 카테고리로 영상을 만드는 날"
흐름 ①플랫폼 지도 슬라이드 · 롱폼과 숏폼 화면 비교롱폼은 끝까지, 숏폼은 멈추게
흐름 ②L컷 · 덕킹 화면 녹화, 점심 구내식당 B롤소리는 먼저, 말할 땐 음악을 낮추기
하이라이트상품 컷신 촬영(흰 종이 · 역광) · 스피드 램프 결과말 없이 컷과 음악으로 갖고 싶게
흐름 ③크루 챌린지 전환 장면트렌드 틀 + 나만의 비틀기
아웃트로썸네일 투표 · 트리에 오너먼트 두 개"다음 시간엔 내 대표작을 만듭니다"

숏폼 버전: 상품 스피드 램프 → 크루 챌린지 전환 → 오너먼트 붙이는 손, 20초. 음원은 업로드할 때 앱 안에서.
