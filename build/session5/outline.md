# 5회차 개요 · 12/1(화) · 카테고리 A to Z ② 말하는 · 만드는 영상 + 대표작

모든 5회차 자료(슬라이드 · 워크북 · 핸드북 5장 · 진행안)의 기준. 수강생 실명 · 개인 사정은 쓰지 않는다(공개 저장소). 교시별 시각은 적지 않는다. **크루 활동 없이 개인 실습**(막히면 옆자리와 서로 돕기). 카테고리 A to Z 7단계(A 정의 → B 레퍼런스 → C 기획 → D 촬영 → E 편집 → F 발행 → G 체크)와 플랫폼 두 갈래(유튜브 롱폼 / 릴스 · 쇼츠 · 틱톡)는 4회차와 같다. 카테고리 번호는 4회차 ①브이로그 ②정보성 · 리뷰 ③상품 이미지 ④공감 상황극에 이어 ⑤~⑦.

## 4회차와 이어지는 점
- 4회차 마지막에 "내 콘텐츠의 메인 스타일"을 정했다 → 5회차는 남은 세 카테고리를 배우고, **메인 스타일로 대표작 1편**을 만든다. 6회차(12/10)는 상영 · 피드백.
- 레퍼런스는 강사가 고르고 분석을 붙인다(4회차와 같은 방식). 슬라이드 레퍼런스 칸은 비워 두고 강사가 채운다.

## 오늘 남는 것
- **대표작 1편** (메인 스타일 카테고리 ①~⑦): 롱폼 16:9 · 2~4분, 또는 숏폼 시리즈 3편, 또는 AI 영상 30초~1분 → 6회차 상영작 후보.
- 대표작에서 잘라 낸 **숏폼 1편**.
- **채널 브랜딩 한 장**(이름 · 소개 한 줄 · 썸네일/커버 규칙 · 시리즈 이름 · 업로드 주기).

## 교시별

### 시작
- 4회차 돌아보기(메인 스타일 한 줄씩 떠올리기) → 오늘의 흐름 → **대표작 재료 점검**: 찍어 온 것 / 4회차 소스 / AI 컷 / 오늘 실습 결과물 중 무엇으로 만들지.

### 1교시 · ⑤ 토크 · 인터뷰 A to Z
- A: 사람을 보러 오는 영상. 1인 토크 · 인터뷰 · 2인 대담 · 팟캐스트형. 강사 진로 · 자기소개 포트폴리오 · 가게 사장/고객 인터뷰. 얼굴이 부담이면 손 · 뒷모습 · 오디오 형식.
- B: 레퍼런스(강사 선정) — 질문과 답 길이, 컷이 몇 초마다 바뀌는지, B롤 위치.
- C: 1인 토크 = 키워드 메모 5줄(대본 통째로 읽기 X), 인터뷰 = 열린 질문 5 + 꼬리 질문. 구조: 누구인지 → 질문 1 · 2 · 3 → 가장 센 한마디.
- D: 눈높이 · 시선(렌즈 또는 진행자 옆) · 폰 두 대(와이드 + 클로즈업) · 마이크/폰은 입에서 한 뼘 · 창을 앞에 · 배경 정리 · 조용한 곳.
- E: ① 군말 · 공백 지우기(자동 캡션 · 군말 찾기 · 대본으로 편집, 3회차 연결) ② 두 카메라를 위아래 트랙에 놓고 말하는 사람 따라 자르기 ③ 센 문장에 강조 자막 + 줌인 + B롤(L컷, 4회차 연결).
- F: 제목(사람 + 인용 한 문장) · 썸네일(표정 + 인용) · 챕터 = 질문 · 숏폼 = 센 한 문장.
- G: 첫 30초에 누구인지 / 소리 깨끗(파형) / 같은 화면 1분 넘게 X / 출연 동의 / 사실 확인.
- 실습: 1분 셀프 토크(내 메인 스타일 소개) 또는 옆자리 인터뷰 3분 → 30초 하이라이트.

### 2교시 · ⑥ 라이브 · 라이브커머스 A to Z
- A: 지금 같이 있는 영상. 라이브 방송 · 라이브커머스 · 다시보기 → 하이라이트 숏폼.
- B: 레퍼런스(강사 선정) — 오프닝 · 상품 소개 · 증거 · 혜택 · 질문 · 마감 흐름.
- C: 큐시트(시간 · 내용 · 화면 · 멘트 · 준비물) · 판매 멘트 구조(문제 → 보여 주기 → 증거 → 혜택 → 지금 사야 하는 이유).
- D: 폰 고정 · 조명 하나 · 상품 자리 · 채팅 보는 두 번째 화면 · 소리 테스트 · 리허설.
- E: ① 긴 녹화본에서 자동 캡션으로 하이라이트 문장 찾기 ② 하이라이트 → 9:16 숏폼 ③ 가격 · 혜택 정보 카드.
- F: 예고(시간 · 혜택) · 다시보기 챕터 · 하이라이트 숏폼 · 광고 표시 · 개인정보(채팅 닉네임) 가리기.
- G: 큐시트대로 / 가격 · 혜택 정확 / 광고 표시 / 개인정보 / 소리.
- 실습: 내 상품(또는 소지품)으로 혼자 3분 라이브 리허설 녹화 → 1분 하이라이트.

### 점심

### 3교시 · ⑦ AI 영상 A to Z
- A: 찍을 수 없는 장면을 만드는 영상. AI 숏드라마 광고 · 브랜드 필름 · AI 단편. ④ 공감 상황극(한 편으로 끝)과 차이: 숏드라마는 이야기 + 제품 · 다음 편.
- B: 3회차 공통 샘플 "한강 단풍" 메이킹(대본 → 스토리보드 → 기준 이미지 → 이미지→영상 → 내레이션) + 레퍼런스(강사 선정).
- C: 20~30초 광고 구조: 상황 → 문제 → 제품 등장 → 변화 → 엔딩 카드. 6컷.
- D(생성): 기준 인물 · 제품 이미지로 일관성, 카메라를 말로(샷 크기 · 앵글 영어), 프롬프트 공식 여섯 칸, 컷마다 2~3번.
- E: ① AI 컷 잇기 · 색 통일 ② 내레이션(Fish Audio) + 효과음 + 음악 ③ 자막 · 엔딩 카드.
- **AI 숏드라마 광고 마스터 프롬프트**(4회차 상품 프롬프트처럼 한 장 배포물): 제품 사진 한 장 + 한 줄 이야기 → 인물 기준 이미지 → 6컷 이미지 → 영상 프롬프트 → 내레이션 대본 → 편집표.
- F: AI 생성 표시 · 실존 인물 · 상표 금지 · 과장 광고 X · 이용 조건 확인.
- G: 인물이 컷마다 같은가 / 손 · 얼굴 오류 / 한 줄로 설명되나 / AI 표시 / 남의 얼굴 · 목소리 X.
- 자동화 맛보기(강사 시연): 기획 → 프롬프트 → 생성을 AI 도구로 잇는 흐름도. 사람이 보는 지점(기획 · 검수 · 사실).
- 실습: 마스터 프롬프트로 6컷 → 20초 광고 초안.

### 4교시 · 끝까지 보게 하는 법 · 채널로 묶기
- 훅 공식 다섯(질문 · 결과 먼저 · 반전 · 숫자 · 공감) — 첫 3초(숏폼) · 첫 30초(롱폼).
- 이탈 막기: 열린 고리 · 장면 바꾸기 · 챕터 · 끝에 다음 편.
- 성공 채널 해부(개인): 내 메인 스타일과 같은 카테고리 채널 하나 → 가져올 것 하나.
- 채널 브랜딩 한 장 + 유튜브 · 인스타 역할 나누기 + 롱폼 1 → 숏폼 3.
- 수익화 경로 지도(광고 · 협찬과 표시 · 제휴 · 내 사업 판매 · 강의 · 제작 대행). 마케팅실무와 겹치지 않게 "콘텐츠 안에서"만.

### 5 · 6교시 · 대표작 제작
- 메인 스타일 카테고리 카드의 C · E · F · G를 따라 편집. 시리즈 첫 편처럼 인트로 · 엔딩 · 자막 스타일 통일(따라하기).
- 재료가 모자라면: 4회차 소스 · 오늘 실습 결과물 · AI 컷으로 보충.

### 7교시 · 업로드 + 6회차 준비
- 대표작 · 숏폼 업로드, 채널 소개 정리(브랜딩 한 장 반영).
- 6회차 상영 준비: 상영작 확정 · 파일 제출(당일 드라이브 한 폴더) · 제작 노트(사람이 한 것 3줄 / AI가 도운 것 3줄 / 가져온 채널).
