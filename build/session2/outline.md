# 2회차 개요 · 10/30(금) · 기획하는 머리

모든 2회차 자료(슬라이드 · 워크북 · 핸드북 2장 · 진행안)의 기준. 수강생 실명 · 개인 사정은 쓰지 않는다(공개 저장소).

## 이번 회차의 두 가지 축

1. **기획**: 아이템 찾기 → 레퍼런스 해부 → 채널 콘셉트 → 기획안 · 대본 → 스토리보드 → 채널 열고 첫 업로드. 수업에서 한 번씩 해 보고, 같은 단계를 3주 과제로 내 아이템에 제대로 한다.
2. **크루 다시 시작**: 1회차는 개별 실습 위주라 크루가 뭉치지 않았다. 2회차는 "크루로 하지 않으면 끝나지 않는 활동"을 교시마다 하나씩 넣는다.
   - 크루 = 앉은 자리 기준 4크루 × 5명(자리 이동 없이 "의자만 돌려 앉기").
   - 역할 4개(크루장 · 기술 도우미 · 기록 · 첫 시청자) + 1명은 "타임키퍼". 명단 · 역할은 수업 첫 5분에 크루가 직접 적는다(크루 시트).
   - 매 교시 같은 의식: 시작 체크인(크루장 확인) → 크루 활동 → "크루 전원 완료" 카드.
   - 강사 오프닝 멘트: "지난주엔 크루를 말로만 만들었어요. 오늘은 앉은 자리 그대로 크루가 되고, 첫 활동부터 크루로 합니다."

## 교시별

### 1교시 10:00–10:50 · 기획이란 무엇인가 (+ 크루 다시 시작)
- 크루 시트 작성 5분: 크루 번호, 5명 이름, 역할, 크루 이름(임시여도 OK).
- 크루 체크인 15분: 과제로 저장한 10편 중 "제일 좋았던 1편"을 1분씩 보여 주고 이유 한 줄 → 크루가 "크루 대표 1편" 선정(3교시 해부 재료).
- 기획이란: "누구에게 · 무엇을 · 왜 · 어떻게"를 찍기 전에 정하는 일. 기획 = 시청자가 3초 안에 "이건 나를 위한 거다"라고 느끼게 만드는 설계.
- 윤성원 PD(스튜디오 솔파) 사례 — 공개 기사 · 인터뷰 기준:
  - 안원잘부: 외부 프로젝트에 원이를 호스트로 제안 → 탈락 → "이거 안 되면 내가 해야겠다" 직접 시작 → 첫 영상 20만 회 → 사투리 · 일본어 기획안이 "거제" 밈의 출발 → 성장 계기를 데이터로 확인.
  - 존이냐박이냐: 같은 출연자도 콘셉트(걸그룹 노래 커버 "기우제", 베를린 클럽 도전기)로 새로워진다. "베를린 클럽을 아는 사람은 대한민국의 1%도 안 된다"는 전제로 기획.
  - ODG: 아이들이 나오지만 어른 시청자를 위한 채널(어린 시절 회상) — 타깃을 뒤집는 기획.
- 기획 원칙 7: 나를 모르는 사람 기준 / 팬덤보다 대중 / 틀은 시작 · 끝 · 지점 몇 개 / 콘셉트는 놀이터 / 출연자 강점에 맞춘 연출 / 구독할 이유 설계("구독하면 ○○한 느낌") / 채널명은 심플하게 또는 궁금하게.
- 기획자의 태도: 새로움은 감정이다 · 알고리즘에 비밀은 없다(콘텐츠가 좋으면 된다) · 안 되면 내가 한다 · 데이터로 확인한다.
- 출처: 위버스 매거진 인터뷰, 유튜브 공식 블로그(2022.5), iMBC 연예(2026.7). 강사는 수업 전 원본 영상 확인. SNS에 도는 "매번 새 기획은 구독자 0명" 인용은 원본 미확인 → 쓰지 않음.

### 2교시 11:00–11:50 · 아이템 찾기
- 내 안에서 찾기 4칸: 경력(오래 한 일) · 사업 · 취미 · 의외의 모습(주변이 "그걸 네가?" 하는 것).
- 시장에서 찾기: 유튜브 · 네이버 검색 자동완성, 인기 영상 댓글 속 질문, 저장 · 공유 많은 주제, 네이버 데이터랩 · 구글 트렌드.
- 네 갈래: 사업 홍보 / 취업 포트폴리오 / 전문가 · 강사 / 개인 채널.
- 실습: ChatGPT로 후보 30개 → 5가지 기준 점수로 3개.
  - 기준(각 1~3점): 계속 만들 수 있나(30편) · 보고 싶은 사람이 있나 · 내가 할 이유가 있나 · 폰으로 찍을 수 있나 · 일 · 수익으로 이어지나.
- 크루 활동 "3개 중 하나 골라 주기": 각자 후보 3개를 말하면 크루원 4명이 "제일 보고 싶은 것"에 스티커(손가락) 투표. 최종 결정은 본인.

### 3교시 12:40–13:30 · 레퍼런스 찾기와 해부
- 플랫폼별 검색: 유튜브(검색 필터: 업로드 날짜 · 길이 · 유형 Shorts, 채널 "인기순" 정렬로 잘된 영상 보기), 인스타(릴스 탭 검색, 저장 컬렉션 만들기), 틱톡(검색 → 필터), 네이버 클립.
- 해부 6칸: ① 누가(채널 · 출연자) ② 누구에게(타깃) ③ 무엇을(주제) ④ 어떻게(형식 · 길이 · 톤) ⑤ 왜 보나(구독할 이유) ⑥ 내가 가져올 것 / 버릴 것.
- 구조 분석: 첫 3초에 무엇이 보이고 들리나 · 컷 수(30초에 몇 컷) · 자막 스타일 · 소리(음악 · 효과음 · 내레이션) · 제목 · 썸네일.
- AI 1차 해부: 영상 링크만으로는 AI가 내용을 정확히 모를 수 있다 → 제목 · 설명 · 자막(스크립트) · 화면 캡처를 주고 6칸 초안 → 직접 보면서 고친다.
- 크루 활동: 1교시에 고른 "크루 대표 1편"을 크루가 함께 해부(15분) → 크루별 2분 발표(첫 3초 · 구독할 이유 · 우리가 가져갈 것 하나).

### 4교시 13:40–14:30 · 아이템 발전시키기와 채널 콘셉트
- 가져올 것 · 버릴 것: 형식은 빌리고 내용은 내 것으로.
- 나만의 각도 공식: [아이템] × [나만의 경험 · 관점] × [형식] = 채널 각도. 예) 정리수납 × 20년 차 강사의 실패담 × 1분 숏폼.
- 타깃 한 사람: 나이 · 상황 · 고민 · 언제 폰을 보나 · 무엇을 검색하나.
- 구독할 이유 한 줄: "구독하면 ○○한 느낌".
- 시리즈 제목 10개(ChatGPT 초안 → 3개만 남기기).
- 채널 이름 · 핸들 · 소개글 · 프로필 · 배너 방향.
- 산출물: 채널 콘셉트 한 장.
- 크루 활동 "나를 모르는 사람 테스트": 짝 · 크루원에게 콘셉트 한 장을 10초 보여 주고 "무슨 채널 같아요?" 답이 내 의도와 같으면 통과.

### 5교시 14:40–15:30 · 기획안과 대본
- 기획안 양식: 채널 콘셉트(누구에게 · 무엇을 · 왜 · 어떻게) + 시리즈 5편 목록 + 대표 영상 1편(제목 · 길이 · 형식 · 훅 · 핵심 장면 3개).
- 대본 구조: 훅(0–3초) → 본론(약속한 것 보여 주기) → 마무리(한 줄 요약 + 다음 행동).
- 훅 6가지: 질문 / 결과 먼저 / 반전 / 숫자 / 공감 상황 / 비포 · 애프터.
- AI 초안을 내 것으로: 내 경험 디테일 3개를 먼저 적고 넣게 하기, 내 말투 샘플(평소 카톡 · 말) 주기, 소리 내 읽고 걸리는 문장 고치기, 과장 · 거짓 정보 지우기.
- 갈래별 예시 기획안 4종(가상): 사업 홍보 = 동네 빵집 "오늘 첫 빵" / 취업 포트폴리오 = 마케터 지원자의 "브랜드 1분 해부" / 전문가 · 강사 = 20년 차 정리수납 강사의 "버리기 전에 1분" / 개인 채널 = 노견과 사는 "느린 산책 일기".
- 크루 활동: 첫 시청자 역할이 크루원 훅을 듣고 "다음이 궁금하다 / 안 궁금하다" 판정.

### 6교시 15:40–16:30 · 스토리보드와 촬영 계획
- 스토리보드 칸: 장면 번호 · 그림 · 샷 크기 · 앵글 · 움직임 · 소리 · 자막 · 촬영/AI.
- 1회차 연결: 샷 크기 · 5샷 시퀀스 · 커버리지 · 숏리스트(1회차 6교시).
- ChatGPT 이미지로 콘티 그림: 장면 설명 + 샷 크기 + 앵글 + "simple storyboard sketch, pencil, no text". 사람 얼굴 · 실존 인물 대신 단순한 인물.
- 촬영 계획표: 장소 · 날짜 · 시간대(빛) · 소품 · 출연자 · 허락받을 것 · 장비.
- 산출물: 대표 영상 스토리보드 3칸(훅 · 핵심 · 마무리).
- 크루 활동: 기술 도우미가 크루원 스토리보드를 보고 "폰으로 찍을 수 있나" 체크.

### 7교시 16:40–17:30 · 채널 열고 내놓기
- 유튜브 채널 개설: 구글 계정 → 유튜브 → 채널 만들기 → 이름 · 핸들(@) → 프로필 사진 · 배너 · 소개 · 링크 → 재생목록 1개(시리즈 이름). 개인 계정과 분리하고 싶으면 브랜드 채널.
- 이미지 규격: 프로필 800×800 권장(원형으로 표시), 배너 2048×1152(모든 기기에서 보이는 가운데 1235×338에 글자 · 로고).
- 발행 단계: 제목(핵심 단어 앞쪽) · 썸네일(맞춤 썸네일은 휴대전화 인증 필요) · 설명 첫 두 줄 · 공개 범위(공개 · 일부 공개 · 비공개) · AI 사용 표시(사실처럼 보이는 합성 · 변경 콘텐츠는 업로드 때 '변경되거나 합성된 콘텐츠' 공개). 기능 이름은 바뀔 수 있음.
- 첫 업로드: 1회차 베스트 컷 또는 15초 채널 예고 쇼츠. 얼굴 · 공개가 부담이면 "일부 공개"로 올려도 된다.
- 강사도 같은 날 새 채널을 열고 첫 쇼츠를 올린다(함께 시작하는 모습).
- 3회차(11/19) 발표 방식 크루 투표: A 전체 앞 3분 발표 / B 크루 안에서 발표 → 크루 대표 1명 전체 발표 / C 갤러리 워크(기획안을 벽 · 화면에 띄우고 돌아보며 스티커 피드백). 글 · 화면 기반 발표는 언제나 허용.
- 3주 과제(10/31–11/18):
  - 1주(10/31–11/6): 아이템 확정, 레퍼런스 10개 수집, 3개 해부 6칸 → 해부 시트 3장.
  - 2주(11/7–11/13): 기획안 완성(콘셉트 · 타깃 · 시리즈 5편 · 대표 영상 1편). 강사가 드라이브 댓글로 한 번 피드백.
  - 3주(11/14–11/18): 대표 영상 대본 · 스토리보드 · 촬영 계획표, 훅 포함 5컷 이상 촬영(3회차 편집 재료).
  - 크루 체크인: 매주 일요일 밤까지 크루장이 단톡방에 "크루 ○ 이번 주 전원 완료 / 남은 사람 ○명" 한 줄.
- 크루 트리 현황판: 오늘 채널을 연 사람 칸에 줄기 스티커.

## 사람의 몫 / AI의 몫
- 사람: 경험 · 감정 · 구체적인 디테일, 최종 선택, 나를 모르는 사람의 눈으로 다시 보기.
- AI: 후보 많이 내기, 1차 해부, 초안, 콘티 그림, 점검(기획 코치 GPT).
