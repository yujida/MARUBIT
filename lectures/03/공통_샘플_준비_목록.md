# 3회차 공통 샘플 · 추가 샘플 준비 목록 (강사용)

3회차는 사이클 1~18을 **모두 같은 공통 샘플**로 따라 하고, 7교시 **나만의 한 편**은 A(준비해 온 내 영상) 또는 B(추가 샘플)로 만듭니다. 이 문서는 수업 전에 강사가 두 폴더를 채우는 체크리스트입니다.

- 드라이브 폴더 두 개: **`3회차 공통 샘플`**, **`3회차 추가 샘플`** (둘 다 "링크가 있는 모든 사용자 · 뷰어")
- 파일 이름은 슬라이드 · 워크북에서 부르는 이름과 **똑같이** 맞춰 주세요. 수강생은 이름으로 찾습니다.
- 공통 규격: **세로 9:16 (1080×1920)** 기본, `04_가로컷`만 가로 16:9. 30fps(01만 60fps). MP4(H.264). 한 컷 5~15초. 폴더 전체 500MB 이하(교실 와이파이로 20명이 받습니다. 가능하면 USB에도 한 벌).
- 주제는 하나로 묶으면 연습본이 한 편처럼 됩니다. 아래 예시는 **"동네 카페의 아침"**. 다른 주제여도 쓰임만 같으면 됩니다.

### 촬영 요령 (한 번에 30분)
- 같은 날 같은 빛에서 찍되 **일부러 한 컷만 색온도를 다르게**(예: 06을 창가 · 실내등 아래) 두면 사이클 7(색 맞추기)이 잘 보입니다.
- 01은 **반드시 60fps**. 30fps로 찍으면 0.5x에서 끊겨 보여 사이클 6 설명이 거꾸로 됩니다.
- 05 · 06은 컷아웃용이라 **배경이 단순하고 사람과 색이 다를수록** 좋습니다(흰 벽 + 어두운 옷).
- 07 · 08은 **삼각대를 절대 움직이지 않기**. 어긋나면 분할 화면 경계가 티 납니다.
- 사람이 나오면 촬영 전에 **수업 자료로 공유한다는 동의**를 받아 두세요(얼굴 · 목소리 포함).

### 직접 찍기 어려울 때: 무료 스톡
- 사이트: Pexels Videos, Pixabay Videos, Mixkit, Coverr 등. 검색어 예: `coffee pour slow motion`, `barista hands`, `person walking past wall`, `messy desk before after`.
- **라이선스는 받기 직전에 사이트에서 직접 확인**하세요(상업 이용 · 수정 가능 · 출처 표시 필요 여부, 인물 · 상표 노출 주의). 조건이 바뀌는 경우가 있습니다.
- 스톡으로는 `02 · 03`(같은 동작 두 크기), `07 · 08`(같은 구도 비포 · 애프터)을 찾기 어렵습니다. **이 네 개만큼은 직접 찍는 것을 권장**합니다.
- 06(한국어 말소리)도 스톡에 드뭅니다. 강사 본인이 셀카로 20초 말하는 영상이면 충분합니다.

## 2. 추가 샘플 (`3회차 추가 샘플` 폴더 · 6~8컷 + 음악)

내 영상이 없는 수강생(B)이 **나만의 한 편**을 만드는 재료입니다. 공통 샘플과 **다른 주제**여야 "따라 하기"가 아니라 "스스로 고르기"가 됩니다.

- 예시 주제: **"동네 꽃집, 꽃다발 하나 만들기"** (또는 주말 시장 · 공원 산책 · 집밥 한 끼)
- 구성 (파일 이름 예):
  1. `B1_훅` 60fps 클로즈업 (꽃잎 · 리본 묶기)
  2. `B2_와이드` 가게 전경 · 작업대 (세로)
  3. `B3_손_클로즈업` 꽃 다듬기 (같은 동작 와이드 컷도 있으면 동작 연결 가능)
  4. `B4_과정` 꽃 고르기 · 포장
  5. `B5_비포` / `B6_애프터` 같은 구도의 작업 전 · 완성 (마스크 도전용)
  6. `B7_말하기` 한두 문장 설명 10초 (자막용, 없어도 됨)
  7. `B8_마무리` 완성 꽃다발을 건네는 장면 (정지 프레임용)
  8. `음악_B` 공통 샘플과 다른 분위기 음원 1곡
- 일부러 **필요 없는 컷도 한두 개** 섞어 두면 "고르기 · 버리기" 연습이 됩니다.
- B로 만든 한 편도 채널에 올립니다. 그러니 **추가 샘플은 강사가 직접 찍었거나 상업 이용 · 재배포 조건을 확인한 스톡만** 넣으세요. 인물이 나오면 업로드 동의까지 받아 두기.

## 3. 수업 전날 확인
- [ ] 두 폴더 공유 설정: 링크가 있는 모든 사용자 · 뷰어
- [ ] 파일 이름이 슬라이드와 같은지 (`01_훅_슬로` … `09_다른장소`, `음악_배경`, `로고.png`)
- [ ] 01이 60fps인지 (파일 정보에서 확인), 04만 가로인지
- [ ] 강사 노트북 CapCut에서 공통 샘플로 사이클 1~18을 한 번 끝까지 (특히 06 자동 캡션 · 05 컷아웃 결과)
- [ ] USB 한 벌 (와이파이 느릴 때)
- [ ] 입장 안내 화면(QR)에 두 폴더 링크
