# 3회차 공통 샘플 · Fish Audio 내레이션 대본

공통 샘플 "한강 단풍, 지금이에요"에 넣을 내레이션입니다. 기본 대본 하나는 강사가 만들어 공통 샘플 폴더에 넣고(`내레이션.mp3`), 편집 방향별 대본 세 개는 수강생이 고른 방향에 맞춰 직접 만들어 보게 할 수 있습니다.

## 만들기 전에

- **목소리:** 한국어 기본 제공 목소리 중 30대 여성, 밝고 차분한 톤. 복제 목소리나 유명인 흉내 목소리는 쓰지 않습니다.
- **길이:** 한 번에 500자까지라 블록 하나씩 붙여 넣습니다(아래 블록은 모두 500자 이하).
- **쉼표 = 숨 쉬는 자리, 줄바꿈 = 조금 긴 쉼.** 숫자와 영어는 한글로 풀어 썼습니다.
- **속도 옵션이 있으면:** 기본 1.0 / 감성 0.9 / 활기 1.1.
- **듣기는 폰으로:** 수강생 PC는 소리가 나지 않으니 폰 브라우저에서 이어폰으로 듣고 고르기. 억양이 어색한 문장만 다시 만들기.
- **감정 태그(선택):** Fish Audio는 문장 앞 괄호 감정 표시를 지원한다고 알려져 있습니다(예: `(happy)`). 쓰는 버전에서 태그가 그대로 읽히면 지우고 쓰세요.

## 1. 기본 대본 → `내레이션.mp3` (약 25~30초)

장면 순서: 01 단풍잎 → 04 전경 → 05 지나가는 사람 → 02 · 03 잎 줍기 → 07 · 08 피크닉 → 06 한마디 → 09 노을 → 로고

```
올가을 단풍, 아직 못 보셨다면, 지금이에요.

퇴근길 한 시간, 한강공원으로 왔어요.

걷는 사람도, 자전거 타는 사람도, 모두 단풍 구경 중이에요.

떨어진 잎 중에서, 제일 빨간 걸 하나 골라 봤어요.

돗자리 펴고, 따뜻한 커피 한 잔이면, 준비 끝.

이 은행나무 길은, 지금이 제일 예뻐요. 다음 주면, 다 떨어질 것 같아요.

해 질 녘 한강은, 단풍보다 더 붉어요.

이번 주말, 한강에서 만나요.
```

(선택) 06 컷에만 쓸 한마디 → `한마디.mp3`
```
이 은행나무 길은, 지금이 제일 예뻐요. 다음 주면, 다 떨어질 것 같아요.
```

## 2. 편집 방향별 대본 (수강생이 골라서 만들기)

같은 영상에 다른 목소리를 얹으면 다른 영상이 됩니다. 4교시 Fish Audio 시연 뒤, 자기가 고른 편집 방향의 대본으로 직접 만들어 보게 하세요.

### 감성 브이로그 → `내레이션_감성.mp3` (느리게 · 낮은 톤 · 약 20초)
어울리는 컷: 11 발걸음 → 02 · 03 → 13 하늘 → 09 노을
```
바스락, 낙엽 밟는 소리에, 가을이 왔다는 걸 알았어요.

천천히 걸어도 괜찮은 길.

고개를 들면, 하늘까지 단풍이에요.

올해 가을도, 이렇게 지나가네요.
```

### 활기 숏폼 → `내레이션_활기.mp3` (빠르게 · 밝게 · 약 15초)
어울리는 컷: 12 자전거 → 05 → 02 · 03 → 08 → 09 + 로고
```
한강 단풍, 딱 이번 주가 제일 예뻐요!

자전거 타고 달리면, 단풍 터널이 쭉.

잎 하나 줍고, 커피 한 잔, 노을까지.

이번 주말, 놓치지 마세요!
```

### 정보형 소개 → `내레이션_정보.mp3` (차분 · 또박또박 · 약 25초)
어울리는 컷: 01 + 큰 제목 → 04 · 05 화면 속 화면 → 07 · 08 분할 화면 → 09
```
한강공원 단풍 구경, 이렇게 준비하세요.

첫째, 해 지기 두 시간 전에 도착하기.

둘째, 돗자리와 따뜻한 음료 챙기기.

셋째, 노을은 강가 쪽 벤치에서 보기.

단풍은 금방 지니까, 이번 주가 기회예요.
```

## 3. CapCut에 넣은 뒤

1. mp3를 드라이브로 PC에 옮겨 CapCut 자료 창에 가져오기
2. 오디오 트랙에 놓고 볼륨: 목소리 0dB, 음악 −15 ~ −20dB
3. 자동 캡션 → 한국어 → 만들기(사이클 9). AI 목소리는 또렷해서 거의 정확하게 나옵니다
4. 문장 사이 빈 곳에서 Ctrl + B로 잘라 장면에 맞게 옮기기
5. 업로드할 때 사람처럼 들리는 AI 목소리면 AI 표시. 무료 플랜 목소리는 수익화 영상에 쓰지 않기

## 참고

- 가상 인물 · 가상 시나리오의 편집 연습용 대본입니다. 정보형 대본의 팁도 실제 공원 안내가 아니라 연습용 문장입니다.
- Fish Audio 크레딧 · 이용 조건은 바뀔 수 있으니 사이트에서 확인하세요.
