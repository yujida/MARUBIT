# 3회차 공통 샘플 · 1단계 대본: "한강 단풍, 지금이에요"

진행 순서: **① 대본 (이 문서)** → ② 스토리보드 → ③ CapCut으로 영상 생성

- 형식: 세로 9:16 쇼츠형 브이로그, 완성 길이 30초 안팎
- 주인공: 30대 여성 한 명(가상 인물). 베이지 트렌치코트, 어두운 머플러, 단발. 모든 컷에서 같은 옷차림이어야 합니다(스토리보드에서 기준 이미지를 만들어 고정).
- 장소: 서울 한강공원 단풍길(특정 공원 이름은 쓰지 않음). 늦가을 오후 → 해 질 녘.
- 소리: 영상 컷에는 대사가 없고, **내레이션은 Fish Audio로 따로 생성**(`내레이션.mp3`). 수업 시연과 사이클 9 자동 캡션 재료가 됩니다.
- 수강생 연습용이므로 컷은 **완성본보다 넉넉하게**(컷당 5~10초) 만들고, 편집은 수강생이 합니다.
- 사이클에 꼭 필요한 9컷(01~09) 외에 **여분 씬 3개(11~13)**를 더 만듭니다. 대본에 자리가 정해져 있지 않은 컷이라, 무엇을 넣고 뺄지 · 어디에 둘지를 편집하는 사람이 고르게 됩니다(아래 4절).

## 1. 이야기 흐름 (완성본 기준 30초)

| 순서 | 장면 | 쓰는 샘플 | 화면 | 내레이션 (TTS) | 화면 글자 |
|---|---|---|---|---|---|
| 1 | 훅 | 01 | 붉은 단풍잎이 화면 가득 천천히 떨어짐 (슬로) | 올가을 단풍, 아직 못 보셨다면 지금이에요. | **한강 단풍, 지금이에요** |
| 2 | 도착 | 04 | 한강과 단풍길이 함께 보이는 넓은 풍경 (가로) | 퇴근길 한 시간, 한강공원으로 왔어요. | |
| 3 | 길 위의 사람들 | 05 | 노란 은행나무 앞을 사람이 천천히 가로질러 지나감 | 걷는 사람, 자전거 타는 사람, 모두 단풍 구경 중. | |
| 4 | 단풍잎 줍기 | 02 → 03 | 허리 숙여 잎 줍기(와이드) → 손이 잎을 집어 올림(클로즈업) | 떨어진 잎 중에서 제일 빨간 걸 골라 봤어요. | |
| 5 | 피크닉 | 07 → 08 | 빈 돗자리 → 같은 구도, 차려진 피크닉 | 돗자리 펴고, 따뜻한 커피 한 잔이면 준비 끝. | 비포 / 애프터 |
| 6 | 한마디 | 06 | 주인공이 카메라를 보며 웃으며 말하는 상반신 | 이 은행나무 길은 지금이 제일 예뻐요. 다음 주면 다 떨어질 것 같아요. | |
| 7 | 노을 | 09 | 해 질 녘 한강과 다리, 붉은 하늘 (고정) | 해 질 녘 한강은, 단풍보다 더 붉어요. | |
| 8 | 마무리 | 09 + 로고 | 노을 위에 로고 · 제목 | 이번 주말, 한강에서 만나요. | 로고 · 구독 |

내레이션 전체 약 150자, 읽는 시간 약 25초.

## 2. 내레이션 대본 (Fish Audio에 붙여 넣을 원문)

숫자 · 영어 없이, 쉼표로 숨 쉴 자리를 표시했습니다. 문장 사이에 한 줄씩 띄우면 컷마다 잘라 쓰기 쉽습니다.

```
올가을 단풍, 아직 못 보셨다면 지금이에요.

퇴근길 한 시간, 한강공원으로 왔어요.

걷는 사람, 자전거 타는 사람, 모두 단풍 구경 중.

떨어진 잎 중에서, 제일 빨간 걸 골라 봤어요.

돗자리 펴고, 따뜻한 커피 한 잔이면, 준비 끝.

이 은행나무 길은 지금이 제일 예뻐요. 다음 주면 다 떨어질 것 같아요.

해 질 녘 한강은, 단풍보다 더 붉어요.

이번 주말, 한강에서 만나요.
```

- 목소리: 30대 여성, 밝고 차분한 톤(브이로그). 한국어 기본 제공 목소리 중에서 고르기(복제 · 유명인 흉내 목소리 사용 안 함).
- 파일: 전체 한 개 `내레이션.mp3` + (선택) 6번 문장만 따로 `한마디.mp3`.
- 여분 씬(11~13)에는 일부러 내레이션을 붙이지 않았습니다. 쓰는 사람이 문장을 빼거나 옮기거나, 음악만 깔지 정합니다.

## 4. 여분 씬 3개 · 편집자의 의도가 들어갈 자리

대본대로만 붙이면 모두 비슷한 영상이 됩니다. 여분 씬은 "정답 자리"가 없어서, 고르는 순간 편집자의 의도가 생깁니다. 같은 재료로 이런 다른 버전이 가능합니다.

| 버전 | 훅(첫 3초) | 중간 리듬 | 엔딩 | 느낌 |
|---|---|---|---|---|
| 감성 브이로그 | `11_발걸음_낙엽` (낙엽 밟는 소리 상상) | 디졸브 전환 · 느린 컷 | `13_나뭇가지_하늘`로 올려다보며 끝 | 차분 · 여운 |
| 활기 숏폼 | `12_자전거_시점` 2배속 | 비트마다 컷 · 휩 전환 · 흔들림 효과 | 09 노을 + 로고 | 빠름 · 에너지 |
| 정보형 소개 | 01 단풍잎 + 큰 제목 | 04 · 05 PiP로 "이런 곳" 설명 | 07 · 08 분할 화면 + "준비물" 자막 | 깔끔 · 설명 |

- 상영회에서 같은 재료로 다른 결과가 나오는 걸 비교하기 좋습니다("왜 이 컷을 첫 장면으로 골랐어요?").
- 사이클 3(15초 가편집)에서 "14컷 중 무엇을 버릴까"가 진짜 고르기 연습이 됩니다.
- 내레이션 문장 순서를 바꾸거나 일부만 쓰는 것도 허용합니다.

## 5. 다음 단계(스토리보드)에서 정할 것

- 주인공 기준 이미지 1장(얼굴 · 옷 · 머리 고정) → 컷마다 이미지에서 영상으로 생성해 인물 일관성 유지
- 07 · 08용 같은 구도 기준 이미지
- 컷마다(01~09 + 여분 11~13, 모두 12컷) 카메라(고정 · 천천히 다가가기 등), 길이, 생성 프롬프트(한국어 · 영어)
- 화면 글자 문구 확정
