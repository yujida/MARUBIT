# 작업 지시서 #01 · 4회차 표지 · 교시 구분 이미지 8장

목적: 4회차 슬라이드(`lectures/04/4회차_카테고리AtoZ_보여주는영상_슬라이드.pptx`) 표지와 1~7교시 구분 화면의 배경. 지금은 그라데이션으로 들어가 있음.

사용할 프로그램: 아트크래프트의 이미지 생성 기능(또는 쓰기 편한 생성 도구) + 필요하면 포토크래프트로 보정.

입력: `lectures/04/이미지_프롬프트.md`의 img01~img08 프롬프트 + 공통 스타일 문장(모든 프롬프트 끝에 붙이기).

해야 할 일:
1. img01~img08을 하나씩 생성 (각 2~3안 중 가장 나은 것 고르기)
2. 포토크래프트로 보정: 왼쪽 1/3을 살짝 어둡게(제목 글자 자리), 색은 초록 · 따뜻한 나무 톤으로 통일, 과한 선명도 X
3. 화면 속 글자 · 로고처럼 보이는 것이 있으면 지우거나 흐리게
4. 아래 규격으로 저장

결과물 규격:
- 파일 이름: `img01.jpg` ~ `img08.jpg` (번호는 프롬프트 문서와 같게)
- 형식 · 크기: JPG, 가로 1536×1024 이상, 품질 90
- 저장 위치: `build/assets/images/s4/` (저장소에 커밋 · 푸시) 또는 이 채팅에 첨부

지킬 것:
- 화면 속 읽을 수 있는 글자 · 로고 · 워터마크 없음
- 실존 인물 · 유명인 닮은 얼굴 X, 한국인 30~50대 성인
- img05(상품 촬영)는 제품 브랜드가 보이지 않게
- img08 벽의 트리 차트는 종이 공예 느낌(우리 수업의 트리 현황판)

끝나면 보고할 것:
- 8개 파일 목록 + 각 파일에서 바꾼 점(프롬프트 수정 · 보정) 한 줄씩
- 다시 만든 것이 있으면 이유

검수(여기서): 규격 · 제목 자리 · 손과 얼굴 · 글자 깨짐 확인 → 슬라이드에 넣고 렌더링 → 고칠 것이 있으면 지시서 #01-2로 다시 드림.
