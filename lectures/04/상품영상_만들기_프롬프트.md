# 사진 한 장으로 상품 영상 만들기 · ChatGPT 프롬프트 (수강생용)

내 상품 사진 **한 장**을 올리면 ChatGPT가 ① 상품을 분석하고 ② 콘셉트를 제안하고 ③ 컷 리스트를 짜고 ④ 컷 이미지를 한 장씩 만들고 ⑤ 각 이미지를 영상으로 바꿀 프롬프트와 ⑥ CapCut 편집 순서까지 만들어 줍니다.

## 쓰는 법
1. ChatGPT(이미지 생성 가능한 모델)에서 **새 채팅**을 연다.
2. 내 상품 사진 한 장을 첨부한다 (밝은 곳에서, 상품이 화면 가운데 크게, 배경은 단순할수록 좋음).
3. 아래 **[마스터 프롬프트]**를 통째로 붙여 넣고, 맨 아래 `[내 정보]` 네 줄만 내 것으로 바꿔서 보낸다.
4. ChatGPT가 단계마다 물어보면 번호로 답한다. 이미지는 한 장씩 만들어지니 "다음"이라고 하면 계속 진행.
5. 마지막에 받은 **영상 프롬프트**를 CapCut AI 동영상(이미지 → 영상)에 이미지와 함께 넣고, **편집 순서표**대로 CapCut에서 붙인다.

---

## [마스터 프롬프트] — 통째로 복사

```
너는 상품 광고 전문 아트 디렉터이자 촬영 감독이야.
내가 첨부한 상품 사진 한 장으로, 인스타그램 릴스용 "상품 이미지 영상"(대사 없음, 15초, 9:16)을 만들 재료를 함께 만들 거야.
아래 순서를 한 단계씩 진행하고, 각 단계가 끝나면 나에게 확인을 받은 다음 넘어가.

[절대 규칙 — 모든 이미지에 적용]
- 상품의 모양, 비율, 색, 재질, 뚜껑·용기 형태, 라벨 글자와 로고는 첨부 사진과 똑같이 유지한다. 새 글자를 만들거나 라벨을 바꾸지 않는다.
- 상품 크기를 과장하지 않는다(손·컵 등 주변 물건과 비교해 실제 크기로).
- 이미지 속에 새 글자, 가격표, 워터마크, 다른 브랜드 로고를 넣지 않는다.
- 실존 유명인이나 특정 인물을 닮은 얼굴을 만들지 않는다. 사람이 나오면 손이나 얼굴 아래쪽(입·턱)만.
- 모든 이미지는 세로 9:16, 사진처럼 사실적인 광고 촬영 스타일.

[1단계 · 상품 분석]
첨부 사진을 보고 표로 정리해 줘: 상품 종류 / 모양 / 주요 색 / 재질·질감 / 라벨·로고 위치 / 대략 크기 / 이 상품의 매력 포인트 3개(눈으로 보이는 것). 잘못 본 게 있으면 내가 고칠게.

[2단계 · 콘셉트 3안]
내 정보(아래)를 보고 서로 다른 무드의 콘셉트 3개를 제안해 줘. 각각: 콘셉트 이름 / 한 줄 설명 / 배경과 소품 / 빛 / 색 팔레트 / 어울리는 음악 분위기 / 참고 키워드(영어). 하나는 "깔끔한 스튜디오", 하나는 "자연·생활 공간", 하나는 "과감한 연출(물방울·가루·흑백 등)"로. 내가 번호로 고를게.

[3단계 · 컷 리스트 (15초 · 8컷)]
고른 콘셉트로 아래 다섯 블록에 맞춰 8컷을 표로 짜 줘: 번호 / 블록 / 장면 설명(한국어) / 카메라(샷 크기·앵글·움직임) / 상품의 움직임 또는 주변 움직임 / 길이(초).
- 훅 1~2컷: 가장 눈길 끄는 순간(움직임이 큰 장면: 붓기·떨어뜨리기·물방울·가루·회전)
- 디테일 2컷: 질감·재료·라벨 매크로
- 쓰는 장면 2컷: 손으로 들기·바르기·먹기·여는 순간
- 히어로 1~2컷: 상품 정면, 깨끗한 배경, 가장 예쁜 빛
- 엔딩 1컷: 상품을 한쪽에 두고 반대쪽에 글자 넣을 빈 공간
길이 합계는 15초 안팎으로.

[4단계 · 이미지 만들기]
컷 리스트 순서대로 이미지를 한 장씩 만들어 줘. 매번 첨부한 상품 사진을 기준으로 상품을 똑같이 유지해.
한 장을 만들 때마다 아래 세 가지를 함께 적어 줘:
 (1) 컷 번호와 블록
 (2) 이 이미지에 쓴 영어 이미지 프롬프트 (다른 도구에서도 다시 쓸 수 있게)
 (3) 상품이 원본과 달라진 곳이 있는지 스스로 점검한 한 줄
그리고 "다음 컷으로 갈까요?"라고 물어봐. 내가 "다시"라고 하면 같은 컷을 고쳐서 다시 만들어.

[5단계 · 영상 프롬프트]
8장이 다 끝나면, 각 이미지를 5초 영상으로 바꿀 "이미지 → 영상" 프롬프트를 컷마다 영어로 써 줘. 형식:
 컷 번호 / 길이 5초 / 9:16 / 카메라 움직임(아주 천천히 다가가기·옆으로 지나가기·고정 중 하나) / 움직이는 것(액체·물방울·가루·천·빛·손 등 자연스러운 물리) / 속도(slow motion 여부)
 그리고 모든 영상 프롬프트 끝에 반드시: "keep the product shape, colors, label and logo exactly the same, no text morphing, no new text, smooth realistic motion"
훅 컷 하나는 "extreme slow motion"으로 써서 CapCut 스피드 램프 연습에 쓰게 해 줘.

[6단계 · CapCut 편집 순서표]
표로: 순서 / 컷 번호 / 쓸 길이(초) / 컷이 바뀌는 순간(음악 박자에 맞출 곳) / 효과(스피드 램프·확대·매치 컷·가리기 전환 중 필요한 것만) / 색 보정 한 줄.
마지막에 엔딩 카드 문구 3안(상품명 · 한 줄 카피 · 어디서 사는지, 각 10자 안팎), 릴스 커버로 쓸 컷 번호, 캡션 한 줄 3안, 해시태그 5개(업종·지역·상품).

[7단계 · 최종 점검]
내가 올리기 전에 볼 체크리스트 5개를 줘: 첫 1초에 상품과 움직임 / 컷이 박자 위에 / 한 색 톤 / 실물과 다르게 보이지 않음(과장 광고 X) / AI 생성 표시 켜기.

[내 정보]
- 상품 이름: (예: 수제 딸기잼)
- 어디에 올리나 / 누구에게: (예: 내 가게 인스타 릴스 / 30대 주부)
- 원하는 분위기: (예: 따뜻하고 깔끔하게 / 잘 모르겠음)
- 꼭 보여 주고 싶은 것: (예: 딸기 알갱이, 병을 여는 순간)
```

## 빠른 버전 (시간이 없을 때 · 한 번에)

```
첨부한 상품 사진으로 인스타 릴스용 15초 상품 이미지 영상(대사 없음, 9:16)을 만들 거야.
상품의 모양·색·라벨·로고는 사진과 똑같이 유지하고, 새 글자나 워터마크는 넣지 마.
① 콘셉트 하나를 정해서 한 줄로 설명하고 ② 훅·디테일·쓰는 장면·히어로·엔딩 5컷 이미지를 차례로 만들어 줘(9:16, 사실적인 광고 촬영 스타일).
③ 다 만들면 컷마다 5초 이미지→영상 프롬프트를 영어로 써 줘(카메라 움직임 + 자연스러운 물리 + "keep the product exactly the same, no text morphing").
④ 마지막에 CapCut 편집 순서(컷 · 초 · 박자) 표와 엔딩 카드 문구 한 줄.
상품 이름: ( )  /  분위기: ( )
```

## 잘 나오게 하는 요령
- **원본 사진이 반이다.** 밝은 창가, 상품 정면, 배경 단순, 라벨이 또렷하게. 흐린 사진은 상품이 자꾸 바뀝니다.
- **라벨 글자가 깨지면** "라벨은 원본 사진 그대로, 글자를 다시 그리지 말 것"이라고 다시 요청하거나, 라벨이 덜 보이는 각도로 바꾸기.
- **상품이 바뀌면 바로 "다시".** 이상한 컷 하나가 영상 전체를 망칩니다.
- 영상으로 바꿀 때 **움직임은 하나만**(액체가 흐르거나, 카메라가 다가가거나). 한 컷에 여러 움직임을 넣으면 상품이 녹아내리듯 변합니다.
- 컷마다 2~3번 만들어 가장 나은 것을 고르기.

## 지킬 것
- 실제 판매용 영상이라면 **실물과 다르게 보이는 컷(크기 · 색 · 양 과장)은 빼기** — 과장 광고가 됩니다. 슬라이드 49 "AI 컷과 섞기 · 지킬 선"과 같은 기준입니다.
- 남의 상품 · 브랜드 사진으로 만들지 않기 (내 상품 또는 연습용 소지품).
- 올릴 때 플랫폼의 **AI 생성 표시** 켜기.
