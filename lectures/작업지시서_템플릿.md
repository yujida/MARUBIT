# 로컬 프로젝트용 작업 지시서 (템플릿)

역할 나누기
- **여기(클라우드 세션)**: 기획 · 작업 지시서(실행 프롬프트) 작성 → 결과물 검수 → 슬라이드 · 자료에 반영 · 커밋
- **로컬 프로젝트(내 컴퓨터, 아트크래프트 · 포토크래프트 등)**: 지시서대로 이미지 · 영상 · 보정 작업 → 정해진 이름 · 위치로 저장
- **주고받는 방법**: 결과물을 이 채팅에 첨부하거나, 로컬에서 같은 저장소 브랜치(`claude/magical-curie-pmjdis`)의 지정 폴더에 커밋 · 푸시 → 여기서 받아 검수

## 작업 지시서 양식 (로컬 프로젝트에 그대로 붙여 넣기)

```
[작업 지시서 #번호 · 제목]

목적: (이 결과물이 어디에 쓰이는지 한 줄. 예: 4회차 슬라이드 교시 구분 배경)

사용할 프로그램: (예: 포토크래프트 / 아트크래프트의 이미지 생성 기능)

입력:
- (원본 파일 경로 또는 생성 프롬프트)

해야 할 일 (순서대로):
1.
2.
3.

결과물 규격:
- 파일 이름:
- 형식 · 크기: (예: JPG, 1536×1024, 품질 90)
- 저장 위치: (예: build/assets/images/s4/)

지킬 것:
- 화면 속 글자 · 로고 · 워터마크 없음
- 실존 인물 · 브랜드 흉내 금지
- (작업별 조건)

끝나면 보고할 것:
- 만든 파일 목록과 각 파일에 쓴 설정(프롬프트 · 보정값) 한 줄씩
- 마음에 안 들어서 다시 만든 것이 있으면 이유
```

## 검수 기준 (여기서 확인하는 것)

| 항목 | 확인 |
|---|---|
| 규격 | 파일 이름 · 크기 · 비율 · 형식이 지시서와 같은가 |
| 내용 | 목적에 맞는 장면인가, 지시한 요소가 다 들어갔나 |
| 품질 | 손 · 얼굴 · 글자 깨짐, 과한 보정, 노이즈 |
| 쓰임새 | 슬라이드 제목 자리(왼쪽 1/3)가 비어 있나, 썸네일은 작게 봐도 읽히나 |
| 규칙 | 실존 인물 · 상표 · 워터마크 없음, AI 생성이면 표시 |
| 반영 | 슬라이드 · 워크북에 넣고 렌더링해서 다시 확인 |
